🐟Tentang Proyek

Website ini dirancang untuk memberikan informasi lengkap seputar hidangan laut segar, sejarah restoran, serta menyediakan fitur Reservasi Langsung (Booking Meja) interaktif yang terhubung langsung ke WhatsApp.

Desain website menggunakan kombinasi warna Biru Laut & Hijau Segar untuk mencerminkan nuansa bahari, disempurnakan dengan Navigation Bar berwarna putih bersih untuk kenyamanan navigasi pengguna.

🚀 Fitur Utama

Navbar Putih Responsif: Tetap berada di atas (sticky) saat di-scroll, dilengkapi dengan menu hamburger untuk layar HP/Mobile.

Beranda & Sejarah: Menampilkan informasi pengertian website, visi restoran, dan sejarah singkat berdirinya restoran.

Katalog Menu Interaktif:
•Daftar produk makanan & minuman lengkap dengan gambar resolusi tinggi dan harga (Rp).
•Filter kategori (Semua, Makanan, Minuman).
•Tombol pintas untuk langsung memasukkan menu pilihan ke form reservasi.

Sistem Reservasi Langsung (Booking Meja):
•Form pemesanan tempat interaktif (pilih jumlah tamu, tanggal, jam, dan area duduk).
•Modal konfirmasi pemesanan tanpa me-refresh halaman.
•Integration direct link ke WhatsApp Official Restoran untuk konfirmasi otomatis.

Informasi Kontak & Media Sosial: 
Menampilkan nomor telepon, WhatsApp, email, jam buka, dan tautan sosial media.
Peta Lokasi Interaktif: Tampilan alamat lengkap dan integrasi Google Maps.

🛠️ Teknologi yang Digunakan

HTML5: Struktur utama halaman web.

Tailwind CSS (CDN): Framework CSS untuk styling modern, responsif, dan fleksibel.

JavaScript (Vanilla JS): Logika interaktif untuk menu mobile, filter katalog, form reservasi, dan modal.
FontAwesome 6: Ikon vektor modern untuk mempercantik UI.
Google Fonts (Inter): Tipografi yang rapi dan mudah dibaca.

📖 Struktur Halaman

Website ini dibangun menggunakan konsep Single Page Application (SPA) dengan 5 bagian utama:
#beranda - Banner utama, Pengertian Website, dan Sejarah Restoran.
#menu - Katalog Makanan & Minuman + Filter Kategori.
#reservasi - Form Booking Meja & Integrasi WhatsApp.
#kontak - Informasi Telepon, Email, Jam Operasional, & Sosmed.
#alamat - Lokasi Fisik & Google Maps Embed.
